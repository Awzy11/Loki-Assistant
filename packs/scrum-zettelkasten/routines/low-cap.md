Low-capacity mode. Run it when the tank is empty after a hard day, or any time the user wants the system to decide for them. It must be fast and low-friction: the person is running on empty.

## Steps

### 1. Read the context
Read today's daily note: the energy property (if the profile sets one) and the task list.

{{energy_note}}

### 2. Confirm the tier
Ask one question, and nothing else before the protocol: **"Partial or Depleted?"** If today's note already says the day started low or the social load was high, suggest Depleted as the default and let the user confirm or correct.

### 3. Surface the protocol
- **Partial:** keep the day, shrink it. Pick one or two low-friction items (admin, physical, already scoped). Defer anything open-ended, decision-heavy or creative. Eat, drink water, step outside for ten minutes. Stop at a time you choose now.
- **Depleted:** nothing carries an obligation tonight. Everything defers except gentle movement if the user wants it. Food, water, a shower, something undemanding, an early night. No planning, no inbox, no decisions.

### 4. Triage today's list
Scan today's unchecked tasks and produce two short columns, **Still on** and **Defer to tomorrow**, following the tier above. No full review, just the split.

### 5. Update today's note
If today's `{{section.reflection}}` section is empty, note the tier the user confirmed and how the day went. Make a targeted edit of that section if it exists, otherwise rewrite the note in full.

### 6. Tell the people who need to know
Ask once: **"Is there anyone who should hear that you are low tonight?"** If yes, offer to draft one sentence the user can say or send before going quiet ("I had a draining day and need twenty minutes, then I'm all yours"). If no, move on.

### 7. Report out
One short paragraph: the tier, the split, one suggested recovery action (default: a short walk), and whether anyone needs a heads-up.

## Rules
- One question maximum before the protocol.
- Keep the report short; brevity is the point.
- If the user adds project work to "Still on" during Depleted mode, answer plainly: "That's a tomorrow task."
- Being depleted is not a failure. Frame everything neutrally and never as a rule.
